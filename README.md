# Python-ATM-Banking-System
A beginner Python project that simulates a simple ATM banking system using Object-Oriented Programming (OOP).

Features

Check account balance

Deposit money

Withdraw money

Validate transaction amounts

Handle invalid numeric inputs using exception handling

Interactive ATM menu

Prevent withdrawals exceeding the available balance

Concepts Used

Python classes and objects

Constructors (__init__)

Instance attributes (self)

Methods

Conditional statements

While loops

User input

Exception handling (try/except)

Functions

How to Run

Clone this repository.

Open the project folder in Terminal.

Run:

python3 atm.py
